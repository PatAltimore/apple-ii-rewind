Applesoft BASIC, cold-booted. A local disk of classic programs is mounted: type CATALOG to list it, LOAD NAME / RUN to run one, SAVE NAME to keep your changes (in this browser). Paddle games like Little Brick Out need 🕹 On-screen controls (turn off “Self-centering” so the paddle holds its place). ⏏ Total Replay to go back.

← ↑ ↓ → Return Esc Navigate the launcher and games Left Alt Open-Apple / button 0   Right Alt Closed-Apple / button 1 Delete Ctrl-Reset — quit the game back to the menu F2 Rewind 5 seconds (also Backspace while fullscreen) 🎮 USB/Bluetooth gamepads act as the joystick

In the menu: “Keys” mode with Arrow keys moves the cursor, Return ⏎ launches, Esc goes back. Older games list their own movement keys; pick that set to have the stick press them. Self-centering off leaves the stick where you put it, for cursor and flight-sim games. Swap buttons if a game expects button 0 on the other side. Menu ⏏ quits a game. Type ⌨ searches by name.
